# Webflow export

Ovdje ide budući sirovi Webflow export. Sačuvati originalna imena i strukturu datoteka radi sljedivosti.

Ove datoteke nisu produkcijski kod i ništa iz ove mape ne objavljuje se izravno. HTML, CSS i JavaScript služe samo kao referenca za sadržaj, strukturu, interakcije i assete.

Za svaki asset koji se optimizira zabilježiti izvorni relativni put i odgovarajući izlaz u `/public/assets`.
