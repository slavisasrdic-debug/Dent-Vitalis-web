# Izvorne fotografije

Ovdje idu najbolje dostupne izvorne fotografije. Datoteke se ne objavljuju izravno i ne smiju se povećavati iznad stvarne rezolucije.

Produkcijska izvedenica u `/public/assets` mora imati dokumentiranu vezu s izvornom datotekom, ciljnu namjenu, dimenzije i format. Prednost imaju optimizirani AVIF/WebP formati uz fallback kada je potreban.
