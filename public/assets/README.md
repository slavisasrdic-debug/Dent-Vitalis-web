# Produkcijski asseti

Ovdje smiju biti samo optimizirane datoteke koje Astro može javno objaviti: slike, fontovi i ostali potrebni produkcijski asseti.

Za svaku sliku čuvati vezu na izvor u `/source-assets`, ne povećavati je iznad izvorne rezolucije te pripremiti optimalne dimenzije, AVIF/WebP izvedenice i responsive `srcset` gdje je koristan. Alt tekst pripada sadržajnom modelu ili komponenti; dekorativna slika koristi prazan alt.
