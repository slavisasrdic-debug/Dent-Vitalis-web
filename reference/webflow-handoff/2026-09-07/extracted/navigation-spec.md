## Interaction scope

Desktop parent navigation link behavior is in custom script `custom-10e10c2088200947` and uses `(min-width: 992px)`. Mobile dropdown state/hover/click rules and animations remain separately in IX2, native data-hover/data-delay attributes and CSS; do not apply desktop navigation redirects in the mobile menu.

The logo subtitle has a JavaScript width calculation after fonts are ready; preserve original expression and retry/load/resize hooks from `custom-cc9ece71d2318662`. `letter-spacing` computed values are viewport/font dependent, so no hardcoded measurement is supplied.

Open-state classes, hamburger/close transitions, overlay/fixed position and z-index declarations are all included. Focus handling and keyboard behavior require separate browser validation.
