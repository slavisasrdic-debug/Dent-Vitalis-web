## Important runtime difference

A shared custom script injects alt text when initial alt is missing/empty. Its filename map and original strings are in custom-4826905c26d397d0. This is not an asset-level/native alt guarantee. Preserve original empty/missing source values; implement approved meaningful alt in Astro markup rather than claiming the script changed Designer assets.

Modal focus return, escape handling, menu keyboard control, reduced motion, contrast and no-JS content need actual browser tests. Source implementations are in interaction recipes; tests have not been claimed here.
