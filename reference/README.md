# Referentni materijali

Ova mapa je izvan Astro produkcijskog builda. Sadrži provjerljive artefakte korištene za vizualnu analizu odobrenog Webflow reference weba.

Ništa iz ove mape ne smije se izravno kopirati u produkcijski HTML, CSS ili JavaScript.

- `webflow-audit.json` — renderirani Webflow DOM, stilovi, breakpointi i mrežni asseti; osjetljivi URL parametri su redaktirani
- `live-site-audit.json` — postojeći višejezični URL inventar s requested/final URL-ovima
- `screenshots/` — desktop, mobile, breakpoint i interaction snimke Webflow reference

Artefakti su snimljeni 2. rujna 2026. Ponovno se generiraju naredbama dokumentiranim u root `README.md`; novi snapshot treba pregledati i commitati kao zasebnu, svjesnu promjenu jer udaljeni webovi nisu nepromjenjivi.
